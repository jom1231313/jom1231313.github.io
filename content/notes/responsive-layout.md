## 화면 너비보다 읽는 경험

반응형 목록을 만들 때 기기 이름마다 열 수를 고정하면 중간 너비에서 카드가 좁아지거나 빈 공간이 커질 수 있습니다. 먼저 카드 제목과 설명을 읽기 편한 최소 폭을 정하고, 남는 공간에 따라 열이 늘어나도록 구성하면 레이아웃 규칙을 단순하게 유지할 수 있습니다.

CSS Grid의 `auto-fit`과 `minmax()`를 조합하면 컨테이너 크기에 맞춰 카드 수를 배치할 수 있습니다. 최소값에 `min(100%, 18rem)`을 사용하면 카드 기준 폭보다 작은 화면에서도 컨테이너를 넘지 않습니다. 페이지의 바깥 여백과 카드 사이 간격은 각각 관리해 변화가 필요한 곳을 쉽게 찾도록 합니다.

```css
.note-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 18rem), 1fr));
  gap: clamp(1rem, 2vw, 1.75rem);
}

.note-body {
  max-width: 68ch;
  overflow-wrap: anywhere;
}

.note-body pre {
  overflow-x: auto;
}
```

글 본문은 목록보다 좁은 읽기 폭을 갖는 편이 좋습니다. 코드와 긴 주소는 별도로 처리해야 가로 스크롤이 페이지 전체에 생기는 일을 막을 수 있습니다. 제목 줄 수가 달라질 때 카드 하단 정보가 어떻게 정렬되는지도 실제 길이의 문장으로 확인합니다.

브라우저 너비만 줄여 보는 확인으로는 충분하지 않습니다. 글자 확대, 긴 한국어 제목, 공백 없는 문자열을 넣었을 때도 탐색과 읽기가 가능한지 살펴봅니다. 콘텐츠를 숨기는 방식으로 맞추기보다 줄바꿈과 여백을 먼저 조정합니다.

- [ ] 작은 화면에서 페이지 전체 가로 스크롤이 없는가?
- [ ] 긴 제목과 코드가 컨테이너 안에 머무는가?
- [ ] 글자 크기를 키워도 핵심 정보가 보이는가?
